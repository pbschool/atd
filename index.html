หากแก้โค้ดใน Apps Script ต้องอัปเดตเวอร์ชันเสมอ:

  1. เปิดชีตระบบด้านบน เลือก ส่วนขยาย > Apps Script
  2. วางโค้ดใหม่และกด บันทึก (Save)
  3. ไปที่เมนู Deploy > Manage Deployments
  4. กดไอคอน ดินสอ (แก้ไข)
  5. ช่อง Version ให้เลือก "New (สร้างใหม่)" เสมอ!
  6. กด Deploy และนำลิงก์ Web App (ที่ลงท้ายด้วย /exec) มาวางด้านบนเพื่อซิงค์
